# Fundamentals-of-Python

This repository contains some of my fundamental projects which I made only to understand python concepts and polish my skills.

Here's a list of what this repository currently have:

## Calculator 
-- > It is a simple program which allows you to perform the four basic arithmetic operations.

## A Simple Quiz 
-- > It is a game-like program which is a quiz. It asks you questions and keeps track of points. It also has a decent interaction system.

## Password Generator 
-- > It is a program which will generate password which is competely random based on how many letters, numbers and sumbols the user want in it.

## Turtle Race (Turtle UI)
-- > It is a program made using turtle library which simulates a turtle race on which you are asked to bet. It is my first UI based project.

## Morse Code Converter (Tkinter UI)
-- > A GUI-based application built using Tkinter that converts text into Morse code. It converts user-input text into Morse code. It uses a CSV file (morse-code.csv) as a data source and handles unsupported characters by replacing them with /. Finally it displays output dynamically on the screen.



## Purpose of This Repository

These projects are focused on:

* Strengthening core Python fundamentals

* Understanding logic building

* Practicing problem-solving

* Exploring basic UI development (Tkinter & Turtle)
